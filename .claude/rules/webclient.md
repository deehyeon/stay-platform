# WebClient 연동 가이드

## 사용 원칙

외부 공급사 연동은 반드시 **Spring WebClient**를 사용한다.  
RestTemplate·RestClient 기반 구현은 사용하지 않는다.


## 병렬 호출

- 여러 공급사는 **동시에** 호출한다
- 한 공급사 호출 실패가 다른 공급사 결과에 영향을 주어서는 안 된다

## 타임아웃 설정

연결 타임아웃(connect timeout)과 응답 타임아웃(response timeout)을 **각각** 설정한다.

```yaml
# application.yaml 예시
supplier:
  a:
    timeout:
      connect-ms: 3000
      response-ms: 5000
```

설정 값과 그 근거(공급사 SLA, 허용 지연 등)를 설계 문서에 명시한다.

## 부분 실패 허용

- 특정 공급사 호출이 타임아웃·에러로 실패해도 예외를 상위로 전파하지 않는다
- 성공한 공급사의 결과만 취합해 응답하고, 실패 사실은 응답 본문에 포함한다

## 실패 판정 통일

두 공급사의 실패 표현 방식이 다르므로 어댑터 계층에서 **동일한 예외 타입**으로 변환한다.

| 공급사 | 실패 조건 |
|--------|-----------|
| Supplier A | HTTP `4xx` / `5xx` |
| Supplier B | HTTP는 항상 `200`. `resultCode != "0000"` 또는 `data == null`이면 실패 |

도메인·애플리케이션 레이어는 공급사 구분 없이 동일한 방식으로 실패를 처리한다.
